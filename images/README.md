# Images

Drop files here with these exact names and they appear on the page automatically.
Until a file exists, the page shows a labelled placeholder in its place — nothing breaks.

| Filename | Where it appears | Notes |
|---|---|---|
| `portrait.jpg` | Infobox, top right | Portrait crop, 4:5. Aim for ~800×1000px. |
| `dashboard.png` | Career section | A dashboard you built. **Blur anything proprietary.** 3:2. |
| `graduation.jpg` | Education section | Graduation or any photo of you. 3:4. |
| `logo-amazon.png` | Career section | Optional. Transparent PNG, ~400px wide. |
| `logo-rkl.png` | Career section | Optional. |
| `logo-desales.png` | Education section | Optional. |
| `logo-gatech.png` | Education section | Optional. |

If a logo file is missing, the plate falls back to the institution's name set in type,
which looks deliberate — so the logos are genuinely optional.

Keep photos under ~500KB each so the page stays fast. Any common format works;
if you use `.png` where the table says `.jpg`, update the `src` in `index.html` to match.
